# Assistente Pedagógico

Aplicativo Android local-first para organização da rotina docente.

## Stack alvo

- React
- TypeScript
- Vite
- Capacitor Android

## Regra de desenvolvimento

O desenvolvimento é conduzido por milestones e pull requests. Nenhuma alteração relevante deve ser feita diretamente em `main` depois que a base do aplicativo for importada.

Documentos de controle ficam em `docs/` e as instruções operacionais para agentes de código ficam em `AGENTS.md`.

## Estado atual

O repositório está sendo preparado para receber a base funcional existente/reconstruída do Assistente Pedagógico. Consulte `docs/STATUS.md` para o estado mais recente.
