# V2 Components

Crie aqui somente primitives comprovadas por telas V2 reais.

Não portar componentes V1 por conveniência.

Princípios:

- API pequena e sem styling legado;
- tokens de `../styles/tokens.css`;
- acessibilidade e touch target >= 48px;
- pressed/disabled/focus/loading explícitos;
- nenhuma abstração especulativa antes do primeiro render da tela que precisa dela.
